# Examples

## 落点对照表

| 事例层（禁止当方案） | 领域层（通用宿主上同样禁止当方案） | 机制层（方案应落这里） |
|---|---|---|
| 这个 PDF / 这个用户 / 这个错误字符串 | 这个知识库 / 这个租户 / 这个 META 键 | 不可信输入、长任务、多实现路由、部分失败 |
| `timeout=60` 写死在一个接口 | 只为「第 N 季」写归一化 | 按任务类型配置超时与重试 |
| `if 特殊用户` | `if 某个知识库` | 用规则 / 策略表达差异 |
| 这个模型挂了写死兜底 | 把业务专名写进默认表 | 按能力路由 + 失败策略 |

判定：领域词在「变化点 / 这个 case」→ 对；在「机制」→ 差。

## 超时（完整档 + 验证）

差：用户 A 在接口 X 上传 PDF 超时，加个 60s timeout。

好：

```markdown
宿主：通用服务 — 各类上传/导入任务
问题类别：长耗时 IO 没有按任务类型设置超时与重试
不变量：每类任务都有明确超时、重试次数和失败语义 ｜ 违反场景：新增任务类型未登记，落到无超时的默认分支，请求挂死
变体：视频上传；另一租户的大 JSON 导入
机制：按任务类型配置超时/重试，统一错误出口
变化点：PDF=60s、视频=180s
这个 case：PDF 上传使用长任务配置
验证：V1 换视频导入仍走同一超时表，只改参数 ｜ V2 test_unregistered_task_type_rejected（改动前挂死，改动后快速失败） ｜ V3 主路径无 "pdf" 字样，只在配置表里
不做：自研任务调度平台
```

## 轻量档 / 跳过

跳过：分页 `offset` 少减 1，直接改，不套模板（单点缺陷，不新增分支）。

轻量档：某接口重试次数写成 0，改成读已有的重试配置。

```markdown
问题类别：重试参数绕过统一配置
机制：所有出网调用从同一份重试配置取值
这个 case：该接口接回配置，删掉硬编码 0
```

## 宿主边界（升层停在领域）

差：多租户报表服务里，用户按部门全称筛选查不到数据（索引里存的是部门编码），机制写成「部门名转部门编码」，验收只换全称和简称两种写法 —— V1 不过：机制自带「存在部门概念」这个领域假设。

好：

```markdown
宿主：通用服务 — 多租户结构化检索
问题类别：过滤条件的表面形式与索引里的标识形式不一致
不变量：硬过滤只用解析后的标识；解析失败或滤空时先按索引字段做字面回退，不直接返回空 ｜ 违反场景：解析器不认识某写法，直接拿原文做硬过滤，返回空结果且无回退
变体：同一租户里全称/简称；另一个租户里产品线名对 SKU 前缀
机制：抽出候选 → 展开别名 → 解析为索引标识 → 过滤 → 滤空字面回退 → 仍空才报无结果
变化点：标识解析器、按租户加载的别名表、参与过滤的字段
这个 case：部门标识解析器 + 该租户的别名表
验证：V1 换一个没有部门概念的租户，只换解析器与别名表 ｜ V2 test_unresolvable_token_falls_back_to_literal ｜ V3 「部门」只出现在解析器与别名表，不在检索主路径
不做：把某一种标识形式写成服务唯一实现
```

## 不变量写不出反例（V2 失败）

差：不变量写「机制保证请求有超时」——找不到违反场景，因为它只是复述实现，测不出来。

好：不变量写「任何出网调用在 T 秒内一定返回或抛超时，不存在无限等待」——反例可写成用例：mock 一个永不响应的下游，断言调用方在 T 秒内收到超时错误。

## 其他速记

| 场景 | 差 | 好 |
|---|---|---|
| 校验 | 在 handler 里加一行判空 | 入口统一校验契约，这个字段是契约里的一条规则 |
| 兼容 | `if (userId === "vip-123")` 走新逻辑 | 差异用规则/策略表达，当前用户是规则表里的一条 |
| 降级 | 这个模型挂了写死返回固定文案 | 按能力路由 + 失败策略，当前模型是路由表里的一个实现 |

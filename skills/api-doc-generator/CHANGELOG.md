# 更新记录

## v2 — 每接口请求与响应示例质量升级

### 新增

- 结构化 `examples`：每接口独立的 `request`、`success`、`error` 三类。
- `state = present | none | not_applicable | unknown`，保证没有 Body/无法确认时也会有明确章节。
- JSON 示例的标准序列化与部分占位符/省略号过滤。
- 每条示例案例必带 `evidence`，便于 Agent 追溯源码。
- `audit` 命令逐接口检查示例章节、状态与 JSON 语法；`--fail-on-review` 严格退出。
- HTTP / WebSocket 参考补丁和跨协议规范，强调事件级真实请求/响应示例。

### 保留

- 单接口、模块、全项目三种模式。
- 单一 `docs/api.md`、安全增量更新、删除证据要求、人工说明保护、无第三方 Python 依赖。

### 兼容性

- v1 **受管文档仍可读取和更新**，但未补充三类示例的旧条目会在 `audit` 中显示 `fail`。
- v1 **JSON 补丁**不再接受；创建新补丁时必须 `schema_version=2` 且提供 `examples`。
- 旧文档如果没有受管标记，继续拒绝自动覆盖，以免误删人工内容。

### 验证

- 32 项标准库单元测试通过，包括格式校验、损坏示例、增量、删除、迁移、人工区域等。
- 演示 HTTP 和 WebSocket 补丁均可正确渲染并完成质量审计。

提示：这些测试验证 Skill 辅助脚本。未在用户实际源码仓库中运行 Claude Code，因此不代表任何真实接口示例已通过代码语义校验。
